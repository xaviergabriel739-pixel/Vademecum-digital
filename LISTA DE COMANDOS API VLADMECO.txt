LISTA DE COMANDOS PRA RODAR O BAGULHO:

Primeiro ative um ambiente virtual (venv) em uma pasta

Primeiro, abra o terminal (ou prompt de comando) e navegue até a pasta onde o ambiente virtual está criado. Em seguida, utilize o comando correspondente:

1. No Windows
Prompt de Comando (CMD):

DOS
<nome_da_pasta>\Scripts\activate.bat
PowerShell:

PowerShell
<nome_da_pasta>\Scripts\Activate.ps1
Nota: Se receber um erro de permissão no PowerShell, pode ser necessário executar o comando abaixo antes para liberar a execução de scripts:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

Rodar a venv com 

.\venv\Scripts\activate 

Depois roda o comando para setar a chave de api na venv:

$env:IA_API_KEY="CHAVE API"

Depois disso é só rodar normalmente e testar com:

python app.py


O link para criar e ver as chaves de api é "https://platform.openai.com/api-keys" por segurança é melhor pegar direto lá pra não ter risco de vazamento pq se a openIA entende que a chave vazou ela para de funcionar, por exemplo a que foi mandada no grupo não funciona
